#  Gym Membership Management System

### A C++ Console-Based Gym Management Application

A simple and practical **C++ project** for managing gym member records through a menu-driven console interface.

---

##  Features

<p align="center">

</p>

| Feature       | Description                    |
| ------------- | ------------------------------ |
| Add Member    | Register a new gym member      |
| View Members  | Display all registered members |
| Update Member | Modify member information      |
| Remove Member | Delete a member record         |
| Search Member | Find a member by name          |
| Exit          | Close the application          |

##  Member Information

The system stores the following information for each member:

* 🆔 Member ID
* 👤 Name
* 🎂 Age
* 💳 Membership Type
* 📅 Join Date
